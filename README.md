<h1 align="center">halodial.github.io</h1>
<p align="center">The website for <a href="https://halodial.github.io">Halodial</a>, a dial for your Mac that opens under your pointer.</p>

The page is plain HTML, CSS and JavaScript with no build step. The dial in the hero (`dial.js`) draws the same dial as the
Mac app on a canvas: its geometry, rim, hold-to-open, Back tile, sliders and click sounds, with each kind of file's
default options. `icons.js` holds the Softstroke icons the app ships.

To preview: open `index.html` in a browser, or run `python3 -m http.server` here and visit http://localhost:8000.
